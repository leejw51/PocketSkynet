# PocketSkynet Privacy Choices

**Effective date: August 3, 2026**

PocketSkynet collects no data, shows no ads, and runs no analytics, so there
is nothing to opt out of in the usual sense. Every privacy-relevant behavior
in the app is under your direct control:

## Choices you control in the app

| Choice | Where | Effect |
|---|---|---|
| Which server receives your data | Login screen → server pill | The app talks only to the PocketSkynet server you enter. Run your own and no third party is involved at all. |
| End-to-end encryption | Room creation | E2EE rooms store only ciphertext on the server. |
| External AI providers | Settings → AI providers | Off by default. The agent uses Apple's on-device model unless you add your own API key; only then is agent conversation sent to the provider you chose. Remove the key to stop. |
| Camera access | iOS Settings → PocketSkynet | The optics run only while open, process frames on-device, and upload nothing. Revoke camera permission at any time. |
| Remembered sign-in | Login screen toggle | "Remember on this device" keeps your credential in the iOS Keychain. Turn it off to be forgotten on close; delete the app to remove it entirely. |
| Agent memory | Knowledge → Forget | Notes you teach the agent live on your server and can be deleted in-app. |

## What you cannot delete

Blockchain transactions are public and permanent once broadcast. The app
shows you a review screen before anything is signed and sent — nothing is
broadcast without your explicit confirmation.

## Do Not Track / sale of data

PocketSkynet has no tracking to disable and sells no data — there is no
mechanism by which the developer could do either, as no data reaches the
developer.
